# aiosamstream

Async Python library behind the Samstream Home Assistant integration.

- `tv` – pairing, token persistence, remote keys, device info, app list/launch (wraps `samsungtvws`)
- `sdb` – pure-Python Smart Development Bridge client (no Tizen Studio binary needed)
- `signing` – per-TV `.wgt` signing (author + distributor XML signatures)
- `wol` – directed Wake-on-LAN

Status: skeleton, no logic yet.
